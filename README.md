# 搞什麼東東？2026台東博覽會民間參與行動紀實　線上翻頁書

把《搞什麼東東？TAITUNG WHAT'S UP》民參計畫行動紀實的電子版 PDF
轉成可以在網頁上翻閱的電子書。

網頁程式與《vuvu好食》《料理快報》相同（StPageFlip 左右翻），詳細步驟見
[`../與山林對話/PDF轉翻頁電子書流程.md`](../與山林對話/PDF轉翻頁電子書流程.md)。
這本跟其他本不一樣的地方是 **PDF 是「跨頁」匯出**，轉檔腳本會自動切半（見下方）。

## 轉檔（一個指令）

在本資料夾底下執行：

```
python tools/pdf2book.py "來源.pdf" docs/pages/minsan2026 "搞什麼東東？2026台東博覽會民間參與行動紀實"
```

`tools/pdf2book.py` 是《vuvu好食》那支再加上「跨頁自動切半」
（做法同 `../tools/split_render.py`）：頁面寬 > 高就沿正中線切成兩頁，
單頁原樣輸出，所以單頁版、跨頁版、混用的 PDF 都能直接轉。

## 本機預覽

```
cd docs
python -m http.server 8768
```

瀏覽器打開 <http://localhost:8768/>。
